# ScrollWise — University Senior Capstone Prototype (v0.6)
Course: CS / HCI 482 Interactive Product Design
Team: ScrollWise (Alex Chen, Maya Patel, Liam O'Connor)

This is a browser-only high-fidelity prototype submitted for capstone grading & evaluation.

Problem Statement:
Undergraduate students spend 3.8+ hours daily on algorithmic vertical feeds (TikTok, Reels) during 5-15 minute campus breaks, inducing cognitive fatigue without retention. ScrollWise transforms passing periods into active micro-learning via 30-second mental model cards and spaced retrieval practice.

Included Features:
- Student Portal Login with quick-fill demo buttons (Student / TA mode)
- Top University Capstone Banner with interactive Project Brief & Grading Rubric
- Full-screen vertical scroll + snap concept feed (keyboard navigation: J/K or Arrow Down/Up, B to save)
- Course subject cards with practical exam & career applications
- Save to Study Deck with live counter & Markdown note export
- Active recall checkpoint quiz with cognitive psychology feedback
- Academic Modules syllabus & featured course seminar reading (unabridged PDF reader)
- Student Learning Dashboard with study streak, cards mastered, and recall accuracy
- Three study atmosphere themes (Campus Dark, Campus Light, Late Night Study)
- Local persistence via browser localStorage (zero remote backend or API required)

How to Run:
1. Double-click index.html in any modern web browser (or serve locally).
2. Click "Student Demo" or "Evaluator / TA Mode" and press "Enter Student Prototype".
3. Test vertical snap scrolling, subject filtering, book reading, and study notes export.
